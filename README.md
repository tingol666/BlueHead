# BlueHead

[GitHub 项目主页](https://github.com/tingol666/BlueHead) · [下载 Release](https://github.com/tingol666/BlueHead/releases)

让 Windows 电脑成为 Android 手机或平板的蓝牙耳机：接收音乐、混合多个媒体来源，并通过电脑麦克风进行通话，或供支持蓝牙输入的录音、录像应用使用。音频通过蓝牙传输，无需同一 Wi-Fi、账号或云服务。

**1.2.2 正式版。** 采用 C# 桌面界面、独立 Python 蓝牙后台和原生 PCM 混音。真机兼容范围及本版验收结果以 Release 附带的验证报告为准。 1.2.2 最终绿色包已由用户真机确认：两设备双向自动接替正常、无碎音或反复切换，微信双向语音、输入输出热切换与挂断后媒体恢复均正常。此前 0.2.1 的双 AAC 同时播放另有历史验收。

## 下载与使用

从本仓库的 Releases 下载 Windows x64 安装包或免安装 ZIP。运行时已包含，无需另外安装 Python 或 .NET。当前优先验证 Windows 11 和 Intel AX211。

1. 首次打开时，从首页点击 **设置蓝牙接收**，按提示选择使用方式、准备适配器。后续可在 **蓝牙与驱动** 管理。
2. “声音与麦克风”方式需要一个专用 USB HCI 蓝牙适配器。应用内的“启用专用接收”会先备份原驱动，再通过管理员授权绑定 WinUSB。使用内置适配器时，其现有蓝牙连接会暂时断开；也可选择外置适配器。
3. 回到 **音频中心**，点击 **开始接收**，在移动设备上连接显示的耳机名称，并开启媒体和通话音频。
4. 点击首页底部带名称和箭头的音量按钮，调节音量、静音或切换声音设备，无需重连蓝牙；设备上的“播放／麦克风发送”分别调节下行与上行。
5. 首页同一行选择出声方式与编码；默认优先高清。“多设备同时播放”可混合声音；“单设备自动接替”在当前设备暂停或停止传音后，接替另一台已请求播放的设备，也可点击名称后的标记立即切换。高清并发断续时，可切换 AAC，或降低至最高 192 kb/s 后重新连接；语音通道使用中禁止更换编码。
6. 停止接收后，可在适配器页面 **恢复系统蓝牙**。独立恢复入口 `BlueHead.exe --recovery` 不依赖蓝牙后台。

“仅接收声音”方式使用 Windows 原生接口，与系统蓝牙共用；需要先在 Windows 设置中配对，编码和播放设备由 Windows 管理。

## 功能与范围

| 功能 | 当前实现 |
|---|---|
| 媒体接收 | SBC、AAC、aptX、aptX HD；实际编码以协商结果为准 |
| LDAC | 实验性，默认关闭；非 Sony 认证解码器 |
| 多设备 | 同时播放／单设备自动接替，独立音量与队列；AX211 双 AAC 已真机确认稳定，双 aptX HD 在本机组合下丢包，不能据蓝牙版本保证全部组合 |
| 语音与麦克风 | HFP，CVSD 8 kHz / mSBC 16 kHz 单声道，一次一个语音设备；录音、录像应用需支持蓝牙麦克风 |
| 热切换 | 接收期间热切换、自动刷新插拔设备；系统默认自动跟随，手选设备消失时回退默认 |
| 驱动管理 | 识别 USB 蓝牙 HCI、备份、WinUSB 更换、原驱动恢复、恢复记录 |
| 音频处理 | 原生有界环形混音、媒体/通话独立缓冲、媒体时钟漂移校正 |
| 音量 | 每设备播放与麦克风发送独立调节，另有设备播放、实体麦克风、电脑声音三个总控，均为 0%–200% |
| 实时数据 | 媒体/通话协议、采样率、实测负载码率、包速率、缓冲与自动重同步计数 |
| 高级麦克风输入 | 实体麦克风 + 电脑播放声音，排除 BlueHead 播放的手机/平板声音；默认关闭 |

高级混合在首页“混入电脑声音”开启，关闭时只显示两个总控、开启后显示第三个，需要 Windows build 20348 以上（Windows 11 支持）。两个来源可各自调节，混合后再应用当前语音设备的发送音量。数字进程排除不能消除麦克风拾到的扬声器外放声。详见 [音量、码率与高级混合](docs/AUDIO_CONTROLS.md)。

默认通话起播缓冲为 30 ms，媒体为 60 ms。**缓冲设置不是端到端延迟实测值。** 不包含声学回声消除；通话建议使用电脑耳机。尚不支持 AVRCP、LE Audio、aptX Adaptive/Lossless 和同时多路通话桥接。

## 开发

- 界面使用说明：[界面与操作](docs/UI_GUIDE.md)。
- 界面：C# / .NET 10 / WPF / WPF UI。
- 蓝牙：固定提交的 Bumble；已修复的 Windows USB 传输源码保存在本仓库。
- 原生：C 混音、libusb、libwdi、FFmpeg 音频库和隔离的 LDAC 解码。
- 构建与打包：[构建说明](docs/BUILDING.md)。
- 实现、数据和驱动恢复：[架构与恢复](docs/ARCHITECTURE.md)。
- 验证范围与真机步骤：[测试说明](docs/TESTING.md)。
- 本轮问题与证据：[代码审查](docs/AUDIT.md)。

```text
bluehead/      蓝牙后台与音频逻辑
desktop/       C# 界面、系统接口、驱动辅助程序
native/        原生混音、启动器和 WinUSB 模板
installer/     安装、升级和卸载脚本
tests/         协议、编解码、生命周期和热切换检查
tools/         构建、自检、基准和发布工具
vendor/        固定版本的上游源码与来源
licenses/      第三方许可证
docs/          使用、开发与验证资料
```

本机目录按 `Bluetooth/source` 与 `Bluetooth/releases` 分开。源码内 `work/` 为构建缓存，`local/` 为私有状态；它们不进入公开源码 ZIP 或 Git 仓库。历史回退文件保存在 releases/archive，包含本机数据，请勿直接公开整个 releases 文件夹。
