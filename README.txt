BlueHead 2.0.0 | 待验收候选 | Windows x64
https://github.com/tingol666/BlueHead

当前源码和本地候选包为2.0.0，尚未完成本版真机验收，未发布GitHub Release。
公开最新版仍为1.2.4；历史实测结果不代替本版验收。

用途：把电脑作为移动设备的蓝牙音频接收器与免提端点。
在电脑听媒体，将电脑麦克风发送回移动设备；无需同一Wi-Fi或移动端客户端。
目标系统为Windows 10 22H2 / Windows 11 x64，自带兼容的.NET Framework。
完整包自带Python控制后台与原生库，无需额外安装Python或现代.NET Desktop Runtime。

安装迁移：2.0候选仅支持新的空目录，不支持覆盖1.x，也暂不支持2.x原地升级。
安装版默认%LocalAppData%\Programs\BlueHead-2，系统显示名为BlueHead 2。
如果使用1.x安装版，请先备份设置、从托盘退出，并在装2.0前完成旧版卸载；
旧卸载器会按提示恢复系统蓝牙，这一步应由使用者安排，不能装2.0后再运行旧卸载器。
安装版配对与设置仍在%LocalAppData%\BlueHead\data，程序目录变化不改变其格式或位置。
便携1.2.4无需卸载，可原样保留回退；2.0绿色版也请解压到新空目录，勿覆盖旧文件。
绿色版如需沿用数据，在两版均完全退出后备份并复制原data；不要同时运行两版。
后续更换本候选安装版也需先退出、备份数据并卸载旧安装，再选择新空目录。

1. 完整安装或解压，运行根目录BlueHead.exe。不要只复制EXE。
2. 首次点击“设置蓝牙接收”。双向语音使用“声音与麦克风”，需一个专用适配器。
3. 按提示备份原驱动并启用专用接收，驱动操作请求管理员授权。
4. 回到首页“开始接收”，移动设备连接显示的名称，开启媒体与通话音频。
5. 每设备“播放 / 麦克风发送”分别调节0%–200%增益；底部总控可静音、调节总量及热切换电脑设备。
6. 开启“混入电脑声音”后出现第三个总控，将其他电脑应用声音与麦克风合并发送，排除BlueHead播放的设备声音。要求Windows build20348+。
7. AVRCP可用时显示曲目信息和上曲/播放或暂停/下曲按钮。未知状态和不支持的操作禁用。
8. 出声方式和编码在首页同一行。高清多设备断续时选择AAC或最高192kb/s，并按提示重连；也可使用单设备自动接替。
9. 完全退出请在托盘右键“退出”。恢复系统蓝牙前先停止接收，在“蓝牙与驱动”恢复；独立恢复入口为BlueHead.exe --recovery。

专用接收会断开所选适配器原有的耳机、键鼠等连接。保留原驱动恢复备份。
绿色版配对/设置在data；安装版在%LocalAppData%\BlueHead\data。
驱动恢复信息在%ProgramData%\BlueHead\Drivers。

媒体支持SBC/AAC/aptX/aptX HD；LDAC实验性且默认关闭。
语音支持HFP CVSD8kHz、mSBC16kHz、LC3-SWB32kHz，以双方协商为准，一次一路语音。
LC3-SWB不是完整LE Audio；蓝牙5.3不能保证双方支持。
iPhone/iPad标准音频、AVRCP和LC3-SWB等新功能仍待本版真机验收，不声明Apple认证。
AVRCP标准音量0%–100%与本地0%–200%增益独立，详情只读显示，不增加额外滑块。
录音/录像应用需支持并选择蓝牙麦克风；电脑不能强制改变移动端应用的录音源。
没有声学回声消除，通话建议使用电脑耳机。
媒体60ms/语音30ms为预缓冲设置，不是端到端延迟实测值。

2.0音频处理使用C/C++；Python保留Bumble控制和USB包分派，并非整栈C或零GIL。
运行时不使用PyAV、NumPy、sounddevice；开发锁文件可保留它们用于离线对照。
本版验证范围见VALIDATION.md，使用与构建见README.md及docs。
