BlueHead 1.2.4 | Windows x64
项目主页：https://github.com/tingol666/BlueHead

运行 BlueHead.exe，无需另外安装 Python 或 .NET。
绿色版：完整解压目录，portable.flag 使配对与设置保存在同目录 data 中。
安装版：配对与设置保存在 %LocalAppData%\BlueHead\data。

1. 首次使用点击首页“设置蓝牙接收”，按顺序选择使用方式、准备适配器。
2. “声音与麦克风”需要专用适配器。启用时先备份原驱动，再请求管理员授权；之后可恢复系统蓝牙。
3. 回到首页“开始接收”，移动设备连接显示的耳机名称，并开启媒体与通话音频。
4. 点击设备的“播放／麦克风发送”按钮分别调节电脑接收、移动设备接收的音量；底部两个总音量控制分别管理播放和麦克风。
5. 点击底部音量按钮，可热切换播放设备和麦克风。各路均支持 0%–200%、静音／取消静音和恢复 100%。
6. 首页“混入电脑声音”开启后显示第三个总控，将电脑播放声音与麦克风合并发给移动设备，排除 BlueHead 接收的移动设备声音。
7. 协议、采样率和实测负载码率实时显示；点击“详情”查看包速率、缓冲与重同步等统计。
8. 停止接收后，在“蓝牙与驱动”恢复系统蓝牙。首页同一行选择出声方式和编码，可多设备同时播放，或单设备自动接替。缓冲等低频参数在高级音频设置中。

独立恢复工具：BlueHead.exe --recovery（无需蓝牙后台）。
请保留 %ProgramData%\BlueHead\Drivers 中的原驱动备份。
更换驱动会断开该适配器原有蓝牙设备；不能在接收期间更换驱动。

默认优先协商可用高清编码，以实际协商结果为准。高清并发断续时可在首页切换 AAC，或降低至最高 192 kb/s。
更换编码会断开当前蓝牙连接，随后请重新连接移动设备；语音使用中禁止更换编码。
单设备自动接替会请求暂停其他媒体流；当前设备暂停或停止传音后，接替另一台已请求播放的设备。名称旁的播放标记也可立即切换。若设备未响应暂停，会提示手动暂停。
通话默认缓冲 30 ms，媒体 60 ms；这不是端到端延迟实测值。
“仅接收声音”方式与 Windows 共用蓝牙，不支持本程序通话和混音控制。
LDAC 默认关闭且为实验功能。当前没有声学回声消除，通话建议使用电脑耳机。

本版验收证据与适用范围见 VALIDATION.md。
