# 原生音频内核

BlueHead 的持续收发、媒体解码、SCO 节拍、PCM 桥接、时钟匹配和设备回调在 C/C++ 运行。
Python 处理配对、协议协商及应用控制；已经建立的音频不通过 Python 传 PCM。
各组件的目录、依赖和所有权见 [ARCHITECTURE](ARCHITECTURE.md)，信号对照结果见
[AUDIO_FIDELITY](AUDIO_FIDELITY.md)。

## 时间与格式契约

- RTP 位置、原始到达时刻和软件呈现进度分开，公共时间单位为 48k 帧、64 位位置。
  PCM 采样率与该时间单位独立；来源环以各自原生帧计数，显示／控制边界显式换算。
- 完整连续包以实际解码帧数推进时间线。RTP 可能按单声道帧、交错样本或未知单位计数，
  也可能保持不变；时间戳差值不用于计算缺口 PCM，也不能单独重置解码器或清空正常音频。
  缺口处理接口不接收 RTP 时间戳；包头时间戳只在分片归属等传输元数据中使用。
  来源工作线程提交累计 PCM 末位置及区间可信度；仅已知的连续区间参与到达差分。
  跨越估计或省略时间时衰减保留的抖动峰值并重锚，不把合成时长当成精确时钟，也不把工作线程排空时间当成收包时间。
- 媒体保留协商采样率的 float PCM；LDAC 原生域支持 44.1/48/88.2/96k。
  PCM／端点边界检查到 384k，不把软件能力当作协议增加了采样率。
- CVSD、mSBC、LC3-SWB 的生产 PCM 分别为 8/16/32k，每帧仍为 7.5ms。
  48k 及 S16 创建接口保留兼容，整数编码只在必需边界量化。
- 麦克风保持实际采集采样率，电脑声音来自排除本进程树的采集路径；两路在语音目标上混合。
  输出采用实际共享端点格式，不修改系统格式，不启用 miniaudio 通用 SRC。

## 单次转换与精度

必要采样率转换与小幅时钟匹配合并为一次 ASRC。源环只有一个呈现消费者，分数位置持续推进，
不通过复制／跳过周期波形修正正常音乐。PI 控制器沿用固定 PipeWire 参考；队列、时长与周期
在同一来源帧单位下计算，保留校正余量及明确上下限。

滤波器、相位值／导数、原生环及端点转换方案在控制侧准备；回调不分配、不等待控制锁。
双精度 Kaiser/Hermite 系数与 SSE2 成对双声道卷积共享计算，左边界按回调准备一次。
同率且无需漂移修正时直接取原样本；混合和增益使用 double 累加，最后转换为 float。
普通信号不增加抖动噪声、不长期压低幅度。过载、增益变化和实际缺口各有独立有限窗口。

非有限数和明显越界 PCM 在污染持久状态前隔离。局部 FTZ/DAZ 避免极小非规格化数耗时尖峰，
调用者浮点环境完整恢复；没有 fast-math。正常低电平 float、24-bit 步进、独立声道与瞬态均作对照。

## 缺口与恢复归属

媒体／语音来源工作线程负责协议丢帧预测。缺口分别判断是否存在、时长是否确定、是否仍有呈现价值，
不能把一次估计直接提升为丢弃真实音频的依据。相关媒体最多延续约 20ms，低置信度快速淡出；
已决定补偿的剩余帧保持静音，恢复交叉淡变约 4ms。
序号缺口与已确认归属的损坏负载提供缺失证据；各编码独立维护分片与 SDU 账本，
共享 `audio_gap_policy.h` 区分已知损坏帧数、未知 SDU 数与省略的补偿。
完整包已验证的编码帧数优先使用，例如 LDAC 整包解码失败不能把四帧损坏记成上一包的一帧。
整个包遗失且没有可靠帧数时，只能估计，不能把时间戳差值当作原始信号长度。
固定容量时长分布仅学习完整、已接纳且解码成功的单元；稳定历史采用众数，变化历史采用较低的中位数并限制猜测。
单个大包不会接管典型时长；持续改变包粒度只更新统计，不重置解码器或清除 PCM。
超预算或无法估计的证据消费一次并单独计数，不作为下一包的隐藏债务，也不触发清空有效音频。
SBC 按完整校验后的帧边界直接解码，避免额外解析器延迟末帧并错误归属成功状态；
AAC 仅在解码器不具备延迟输出能力时学习本次 SDU 时长。
一个损坏 SDU 的丢失分片与被拒绝尾片属于
同一缺口，不能重复补偿；多个独立损坏 SDU 也不能合并成一次损坏。
解码器及来源重置来自显式暂停／重新配置、完整验证的新流或明确的解码失败恢复，不能由 RTP 数值跳变或估计缺口大小推断。
未确认来源的坏包不得修改当前来源的序列、分片、解码器或已排队 PCM。
语音定时器必须同时检查当前消费代次已真正起播及实际队列余量，预缓冲时间的增长不代表已播放。
就绪状态与来源代次、启用／连接控制代次一起发布，旧回调不能在关闭再开启后重新宣告就绪。
原生 FIFO 还包含 SRC 的未来滤波支撑，不能把它全当成可立即播放的时间。
消费者用同一次有界发布提交读位置、实际滤波支撑和就绪代次；工作线程的一次快照若不稳定就延后判断，不自旋。
可播放库存扣除这部分支撑，并立即计入之后新写入的 PCM；容量和缺口投放预算仍使用原始库存。
CVSD 没有可识别的接收序号，不按收包静默定时制造原始帧；控制器明确标记的损坏仍使用对应解码器的补偿。
其真实帧边界保护不等于每次普通到达都失去时钟置信度。

H2 定时补偿单独记录已提交的时间与可识别序号，不能因撤销序号信任而忘记已经输出的补偿。
可识别的晚到原帧不重放，也不再次产生同一缺口。仅损坏负载而帧头字节可靠时保留序号证据；
帧头被标记为损坏、失去同步或超过两位序号的可判别窗口时，只降低身份置信度并标记后继真实边界，
不从可疑序号／重同步字节数计算额外 PCM，不重建正常解码器或清空队列。
未知帧头不能确认或再次补偿定时器已覆盖的时间；无法排除完整序号周期时，也不能永久拒绝新一圈的真实音频。
收包窗口以完整且可信的 H2 输出为锚，容纳批量与分片；原始 USB 片段间隔不直接代表音频丢帧数。

ISO 使用已配置的帧时长与每 SDU 帧块数计算确定时长，保留控制器时间戳与声道对齐职责。
定时缺失与左右声道等待共用实际播放余量；已有真实库存时，固定收包宽限到期不等于播放期限已到。
初始缺侧只有在同侧更晚的完整、已准入 SDU 证明旧侧无法再接纳，或实际呈现期限到达时才封口，
不能用合成音频填满预缓冲。较大同代次序号缺口可触发解码器恢复，但不清除已排队真实 PCM 或累计位置。

同一有效媒体会话内的解码器修复与来源退役分开。`bh_media_recover_decoder` 保留未读／部分读取的
float PCM、有效配置、来源位置和同格式 SWR 状态；只退役尚未消费的失败证据，不能再按连续错误次数补一遍。
AAC 保留 LATM StreamMuxConfig，后续 useSameStreamMux 继续可用；独立对照使用相同的预热与 flush 生命周期。
暂停、已验证的新 SSRC、过期会话和格式／槽位代次变化仍按硬边界清除旧音频，不能被软恢复覆盖。

解码器修复在后继真实 PCM 的同一标记环中使用独立类型，普通不确定边界不触发波形处理。
是否有实际可听前驱由消费者在抵达边界时判断，不能使用解码线程缓存的最后一帧。
连续真实播放中的修复接缝使用约 1ms 的双声道共权重窗口；已缺音淡出、已有恢复合并、没有前驱或实际静音时
沿用现有恢复责任，不叠加第二个窗口，也不唤回旧声音。解除静音后的有效前缀及尚未结束的启用渐变按实际位置判断。
标记的事件位置与 SRC 音频插值分开：只规范事件身份的浮点尘，不改变滤波系数和正常 PCM；
分数重访、跨步、回绕及端点变化均只消费一次。已发布修复高水位仅作快路径提示，与 PCM 绝对游标／代次绑定，
消费者不扫描已释放的槽位；没有待处理修复时跳过标记扫描和增益轨迹镜像，不增加常态转换或排队。

估计或省略的缺口在后续真实 PCM 的实际环形位置携带一个字节边界标记。PCM 与标记由同一写游标发布，
部分读取、回绕、原生 SRC 和隔离解码进程均保留对应位置，不能用累计补偿计数猜测某批 PCM 的前缀。
渲染消费者独占呈现欠账：可以过期边界前已经补过的前缀，到不确定边界即取消剩余未经证实的欠账，
保留后面的真实音频，不因此清环、重建滤波器或再次预缓冲。正常无欠账路径不扫描标记。
重缓冲恢复的积压修整也必须遵守同一边界，不能仅凭目标库存丢掉边界后的真实样本。
每次解码的补偿预算来自原始到达时刻、实际库存与剩余容量，只能缩小原有上限，并先预留当前真实 SDU。
AAC 在实际解出帧长度后才作预留，历史分位值不是安全容量上界。耗尽或已到期的预算不能由下一包重新激活。
读到的库存只是保守快照，不是消费者欠账的所有权转移；最终仍由消费者在实际位置协调。
渲染回调仅做有限末端淡出／衔接，不搜索周期。真正持续饥饿才进入一次重缓冲，不无限生成不存在的原始信号。
采集、媒体、语音和 USB 故障分别隔离，恢复退避及旧路由保护见 [RECOVERY](RECOVERY.md)。

## 所有权与关闭

USB/HCI 只有一个物理所有者。端点准备后必须先停止／等待旧渲染消费者，再启动新消费者；
失败保留可用旧路由，不通过重连蓝牙完成本机热切换。每个来源拥有自己的前视声音与历史，
清除／复用一路不清除另一路。

逻辑清除位置在同一游标域内单调，后续最大库存修整不能把它倒退而重新播放旧音频。
逻辑上已经退役的样本仍可能由正在执行的旧回调读取；物理槽位是否可以重用继续由实际读游标决定，
不能用逻辑清除位置提前覆盖。格式或槽位复用只有在旧读者退役后才开始新的游标域。

每个不可变端点方案保留底层混音器引用。正常关闭先停止回调；异常先关闭外层所有者时，
存活方案只输出静音，最后一个方案退役后再释放存储。分配失败在发布格式前回收临时对象，
旧来源的格式和 PCM 继续有效。此关系由编译生产 C 源码的分配失败／释放平衡探针验证。

发布游标前暂停生产者，验证消费者不读取未发布内容；环形标记与正常 PCM 同时作逐样本对照。

虚拟时钟用真实原生 PCM 运算加速，不需要等同长度的墙上时间。稳态回放要求零期限缺口；
主动阻塞解码器再叠加丢包的检查保留缺口／过期计数，要求影响有界且不重缓冲、重复过期或搜索周期。
微基准包含测量调用与调度开销，不是蓝牙端到端延迟。当前版本实际命令、摘要和结果见 Release 的
`VALIDATION.md`；旧构建结果不能代替新二进制验证。
