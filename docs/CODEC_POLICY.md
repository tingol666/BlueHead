# 连接与编码

## 全局偏好与当前连接

首页的媒体编码是**首选**，右侧设置按钮打开“连接与编码”：

- **优先 LE Audio / LC3**：开启 LE Audio 服务与发现；双方支持、发送端允许时使用 LC3。音频通道尚未传来可解码数据时，不中断已有经典媒体。界面区分已连接、通道就绪与实际 LC3 播放。
- **仅经典蓝牙**：关闭 LE Audio 服务和广播功能，使用 A2DP 媒体与 HFP 语音。此项与应用设置中 LE Audio 开关旁的选项同步。
- **允许的经典编码**：已勾选且本机解码器实际可用的格式一起向对端公布。SBC 保留为兼容项。未启用或不可用的格式不会被伪报为可用。
- **首选媒体编码**：影响端点顺序，不隐藏其它允许项。自动模式优先已启用的高清格式；发送设备仍有编码选择权。

修改自动保存。连接偏好在下一次开始接收生效；经典编码列表和首选用于下一次设备媒体连接。已有连接不会因保存偏好而断开，也不会后台请求管理员权限。

## 单台设备的临时调整

在设备 **“…” → 编码与音质** 中读取对端真实媒体端点，与本地允许能力求交集。选择编码及可用参数，点击 **应用到此设备**。只有本次逻辑连接生效，断开后恢复全局设置，不写入设备音量记录。

| 参数 | 范围与限制 |
|---|---|
| 编码与采样率 | 只列出双方能力交集；不通过软件升采样伪装成更高传输采样率 |
| LHDC 位深 | 双方明确支持的 16 / 24 bit |
| AAC 码率 | 可协商的码率上限，实际发送码率仍由对端决定 |
| SBC / AAC 质量范围 | 限制位池／码率上限；不是强制对端编码器的私有质量档位 |
| LDAC / LHDC 质量档位 | 不伪造远程控制能力；界面说明由发送设备决定 |
| LE Audio / LC3 | 显示实际配置；单播参数由发送设备协商，不用经典 AVDTP 命令调整 |

实际码率统计已接收的压缩音频负载，不等于设置的上限或无线总速率。暂停时归零。未采用首选、未建立 LE 音频或调整失败时，设备详情显示具体原因。

## 控制与恢复边界

控制操作只使用既有信令连接，不增加 USB/HCI 所有者，PCM 和实时音频仍由原生后台处理。

同编码调整先暂停，再协商重配置；跨编码或对端不接受重配置时，重建这一台的媒体流。失败后有界尝试恢复原配置，不重启控制器或其它设备。对端仍不接受时，提示只重连这一台。通话、录音或录像使用麦克风期间不调整媒体编码。

每次请求带独立编号与连接令牌，过期连接不能被旧窗口修改。事务匹配信号类型和标签，超时标签在该信令连接内隔离，迟到响应不会完成新请求。媒体流的旧关闭回调不能解绑后继音频。能力读取、调整和恢复均有期限；异常不会形成无限重连循环。

LE 发现使用可连接扩展广播、完整名称、耳机外观与 ASCS/CAS 服务数据，并保持双模公共身份一致。服务缓存只保存匿名身份摘要与订阅状态；已绑定且订阅的对端在数据库改变后收到 Service Changed。对端不接受缓存刷新时会给出重新配对说明，不把经典音频标成 LC3。
