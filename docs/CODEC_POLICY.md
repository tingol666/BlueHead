# 连接与编码

## 全局偏好与当前连接

首页的媒体编码是**首选**，右侧设置按钮打开“连接与编码”：

- **优先 LE Audio / LC3**：开启 LE Audio 服务与发现；双方支持、发送端允许时使用 LC3。音频通道尚未传来可解码数据时，不中断已有经典媒体。界面区分已连接、通道就绪与实际 LC3 播放。
- **仅 LE Audio / LC3**：只开放 LE 音频入口，不提供经典媒体与语音，也不自动回退经典连接。适合重新配对 LC3；按窗口内“LE 配对指南”操作。
- **仅经典蓝牙**：关闭 LE Audio 服务和广播功能，使用 A2DP 媒体与 HFP 语音。此项与应用设置中 LE Audio 开关旁的选项同步。
- **允许的经典编码**：已勾选且本机解码器实际可用的格式一起向对端公布。SBC 保留为兼容项。未启用或不可用的格式不会被伪报为可用；每个编码旁的小齿轮打开其参数设置。
- **首选媒体编码**：影响端点顺序，不隐藏其它允许项。自动模式优先已启用的高清格式；发送设备仍有编码选择权。

修改自动保存，不会主动中断已有连接，也不会后台请求管理员权限。经典编码的允许列表、首选及参数修改后，需要在发送设备的蓝牙设置中**断开电脑耳机，再重新连接**。修改 LE 连接偏好后，需要在 BlueHead **停止接收 → 开始接收**，再重新连接发送设备。首页会提示需要完成哪一步，保存设置不代表当前音频已经改成了新格式。

## 每种编码的参数

在“连接与编码”中点击编码名称旁的小齿轮，设置该编码允许的格式。每种编码分别保存，全局适用于之后的设备连接。参数只提供本机实现支持的范围，发送设备还必须支持相同格式；最终协商结果以设备卡片为准。保留“自动”时允许完整可用范围，不会强制降低质量。

| 参数 | 范围与限制 |
|---|---|
| SBC / AAC / aptX / aptX HD 采样率 | 自动，或 44.1 / 48 kHz |
| LDAC 采样率 | 自动，或 44.1 / 48 / 88.2 / 96 kHz |
| LHDC 5.0 采样率与位深 | 自动，或 44.1 / 48 / 96 / 192 kHz；16 / 24 bit |
| AAC 码率上限 | 自动，或 128 / 192 / 256 / 320 kb/s；实际发送码率仍由对端决定 |
| SBC / AAC 质量范围 | 限制位池／码率上限；不是强制对端编码器的私有质量档位 |
| LDAC / LHDC 质量档位 | 由发送设备控制，电脑端不提供无法生效的远程档位设置 |
| LE Audio / LC3 | 单播格式由双方协商，不受经典编码参数控制 |

指定采样率或位深会限制向发送设备提供的范围，不是将收到的声音升采样或增加有效位深。双方没有共同格式时，发送设备可能选用其它已允许的编码。高清多设备播放出现断续时，可改用 AAC、调整其码率上限后重连，或选择单台自动接替。

实际码率统计已接收的压缩音频负载，不等于设置的上限或无线总速率。暂停时归零。设备卡片显示当前真正使用的格式与可获得的回退原因，不能仅根据首选项判断已经生效。

实时详情显示实际的单声道、立体声、联合立体声或双单声道模式，以及 LHDC 协商的样本位数；协议未提供源位深时显示“未单独协商”，不把内部浮点处理格式当作传输位深。

## 控制与恢复边界

控制操作只使用既有信令连接，不增加 USB/HCI 所有者，PCM 和实时音频仍由原生后台处理。

经典编码设置在设备重新连接时参与能力公布与协商。软件不提供单设备编码热切换，也不会为了应用偏好自动重启控制器或断开其它设备。本机播放设备、麦克风和电脑声音采集来源的热切换仍可在接收期间使用，无需重新连接蓝牙。

LE 发现使用可连接扩展广播、完整名称、耳机外观与 ASCS/CAS 服务数据，并保持双模公共身份一致。服务缓存只保存匿名身份摘要与订阅状态；已绑定且订阅的对端在数据库改变后收到 Service Changed。对端不接受缓存刷新时会给出重新配对说明，不把经典音频标成 LC3。
