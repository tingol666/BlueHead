# 界面与操作

本页对应 2.1.5 源码界面。常用操作在音频中心，驱动准备在“蓝牙驱动设置”，低频选项收在“设置 → 高级音频设置”。

## 先弄清蓝牙使用方式

首页“蓝牙使用方式”右侧的说明按钮可随时查看差异。

| 选项 | 适合什么情况 | 你需要做什么 |
|---|---|---|
| Windows 共用（基础） | 只想在电脑听音乐、视频，保留蓝牙键鼠等系统连接 | 在电脑的 Windows 蓝牙设置中添加并配对手机／平板，回 BlueHead 点右上角“开始接收”，再在设备上播放媒体 |
| BlueHead 专用（进阶） | 还要使用电脑麦克风、媒体编码选择、多设备或 LE Audio | 为一个正确选中的蓝牙适配器切换专用驱动；开始接收后，在手机／平板连接显示的电脑耳机名称 |

专用方式占用所选适配器，其原有的系统蓝牙连接会断开。如果没有其他系统适配器，Windows 的蓝牙开关会消失。想保留蓝牙鼠标、键盘或耳机，可保留基础模式，或另用一个受支持的 USB 适配器。

## 切换驱动：按页面从上往下操作

1. 先停止接收，再打开左侧 **蓝牙驱动设置**。
2. **第一栏选择电脑的蓝牙设备**，核对名称与位置，避免选错另一块适配器。
3. **第二栏选择蓝牙使用方式**，下面会说明用途、影响及当前实际状态。
4. 若需要改驱动，页面显示“待你确认”。按页底右侧的操作按钮继续：系统驱动下为 **备份并启用专用蓝牙**；专用驱动下为 **恢复 Windows 蓝牙** 和 **修复专用蓝牙**。
5. 驱动操作由 Windows 请求管理员授权。成功后方式才生效；取消、失败或离开页面不会仅保存一个与实际驱动不符的选项。已就绪的驱动不要求重复安装。
6. 完成后回音频中心，手动点 **开始接收**。程序不会因为改设置自行开始接收。

“恢复 Windows 蓝牙”用于重新使用系统蓝牙键鼠等设备；“修复专用蓝牙”用于已使用专用驱动却无法启动的情况。页面显示操作进度和结果。故障后需要原厂初始化时，先由你点击修复，不会突然弹出管理员授权。

显示“被占用”时，先退出其他使用蓝牙的程序；仍无法修改驱动，重启电脑后重试。显示 **“驱动恢复完成，请重启电脑”** 时按提示重启，不必反复恢复。主程序后台不能启动时可运行 `BlueHead.exe --recovery`。

## 音频中心

| 位置 | 含义与操作 |
|---|---|
| 右上角开始／停止及旁边状态 | 启动或停止接收；未准备好时显示具体下一步 |
| 蓝牙使用方式 | 显示当前基础／进阶模式；说明按钮解释准备步骤和影响 |
| 多设备播放 | 同时连接多台设备时，选择全部同时播放，或一次一台自动接替；说明末尾显示连接上限及当前数量 |
| 媒体编码 | 选择经典 A2DP 媒体编码，按右侧按钮保存或应用重连；不改变 HFP 或 LE Audio 语音编码 |
| 设备名旁的切换播放 | 单台模式时立即听这个设备；它停止传音后可自动接替其他正在播放的来源 |
| 设备“播放”音量 | 这个设备在电脑的声音，0%–200% 和独立静音 |
| 设备“麦克风发送”音量 | 电脑发给这个设备的麦克风／混合声音，0%–200% 和独立静音 |
| 协议、采样率、码率旁的详情 | 实时计数、标准音量、协商时延或语音数据；空闲时码率归零 |
| 曲名旁媒体按钮 | 控制来源设备的播放器；没有能力或状态未知时禁用，不猜测播放状态 |
| 底部“设备声音” | 所有接收声音的总增益，及电脑播放设备 |
| 底部“电脑麦克风” | 实体麦克风增益，及电脑输入设备 |
| 同时发送电脑声音 | 将其他电脑应用声音与麦克风合并，开启后出现“电脑声音”总控 |

音量按钮有图标、名称、百分比和下拉箭头。展开后可拖动滑块、静音、恢复 100%；取消静音恢复此前值。输入输出可在接收期间切换，选择系统默认时自动跟随插拔与系统变化。整体暂停麦克风发送也会暂停电脑声音混合发送。

AVRCP 标准设备音量、LE VCS 标准音量与本地增益独立，设备端调音量不会把本地 175% 改写为标准值。VCS 控制共享的 LE 播放音量；设备端 MICS 静音不能取消电脑端的隐私暂停。

电脑声音混合排除 BlueHead 进程树自己的播放，避免数字返送；实体麦克风仍可能拾取扬声器声音，建议使用耳机。录音、录像等应用需支持并选择蓝牙麦克风。

## 编码、LE Audio 与广播

通常保留“自动 · 优先高清”。LHDC 5.0 在首页选中后自动启用；也可在 **设置 → 高级音频设置** 中开启，让自动协商包含 LHDC。LDAC 仍需单独启用。实际结果以设备卡片为准，不支持的编码不能靠选择框强制开启。

要使用 LE Audio，在 **设置 → 高级音频设置** 开启 **启用 LE Audio（LC3）**，保存后开始接收。开关下方显示这个适配器的媒体接收、麦克风发送和广播接收是否可用。首页媒体编码用于 A2DP；LE Audio 自动协商 LC3。对端可能同时提供经典和 LE 连接，在界面中合并为同一个设备。

收听广播：在发送设备开启音频分享／广播音频；打开左侧 **音频广播**，点击 **搜索附近广播**，再点击对应广播的 **播放**。需要密码时输入发送端提供的密码，多个节目时选择节目。广播音量独立可调，同时受“设备声音”总控影响。停止播放释放广播连接，停止搜索只停止发现列表。详见 [LE Audio 与 LHDC](LE_AUDIO.md)。

高清多设备持续断续时，可手动选择 AAC 后应用重连，或选单台自动接替。连接数量并不保证无线带宽足够同时播放全部高清流，软件不会自动把你的编码降档。安静的音乐片段不作为暂停判断。

## 托盘、设置与诊断

单击托盘图标显示主界面；关闭窗口默认留在托盘，完全退出请右键托盘 → **退出**。弹层可点外部或按 Esc 关闭。

高级音频设置包含起始缓冲、最大连接数和协议开关。经典媒体／语音的起始缓冲不是端到端延迟；LE Audio 按协商呈现时延分配现有队列、端点与滤波预算。

帮助与诊断可刷新状态、导出匿名计数，不录音。连接断开、旧会话关闭或驱动恢复时，界面根据真实状态更新，不需要靠手动切换播放来“刷新”设备。
